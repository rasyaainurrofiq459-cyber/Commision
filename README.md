# Website Commission Photo Editing & Manipulation

## Cara menambah foto
1. Taruh file foto di folder `photos/` (JPG, PNG, atau WebP; kecilkan ukurannya, sebaiknya di bawah 1 MB per foto).
2. Buka `photos.js`, lalu tambahkan satu baris untuk tiap foto.
3. Upload ulang ke GitHub (Add file -> Upload files). Website otomatis diperbarui.

## Hal yang perlu diganti
- Nomor WhatsApp: `WA_NUMBER` di `index.html`.
- Nama studio dan harga: teks di `index.html`.
